# wg-gesucht-mcp

MCP server for WG-Gesucht.de, so personal AI agents can search flatshares, track listings and handle the tedious parts of the room hunt.

Forked from [wg-gesucht-cli](https://github.com/smlfg/wg-gesucht-cli), developed independently. Part of the [Human-Agent-Interface](https://human-agent-interface.com).

Status: work in progress.
